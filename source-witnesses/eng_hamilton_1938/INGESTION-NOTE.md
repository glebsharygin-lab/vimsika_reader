# Hamilton 1938 Ingestion Note

The first supplied Hamilton PDF contains scanned introduction pages and no extractable translation text layer.

The second supplied Hamilton PDF contains the English translation and facing Chinese text pages. It also has no text layer, so the English translation was recovered with local Windows OCR and segmented by semantic stanza anchors into `passages.json`.

The English witness is now integrated as a provisional OCR witness. Its typography, footnotes, Sanskrit forms, and passage boundaries still require scholarly proofing against the scan.

The facing Chinese text was OCRed separately, but vertical Chinese OCR order is not yet reliable enough to expose as a live corpus witness. It is preserved for proofing in `source-witnesses/zho_hamilton_xuanzang_1938/`.
