# Private manuscript bookmarks

In Manuscripts, open **Research → Private bookmarks**, optionally name the current
location, and select **Bookmark this location**. A bookmark stores the selected
surface, line, reading layer and logical passage, plus the citation and manuscript
version at the time it was saved. Saving the same location again updates that
bookmark rather than creating duplicates.

Open bookmark returns to that location and clears the text search so the selected
line is visible. On a phone it opens the Text panel. Missing locations are marked
unavailable and retained; they are never silently redirected. When the manuscript
version has changed, the current reading is displayed and the earlier citation
remains available. A bookmark is a navigation aid, not an archived transcription.

Bookmarks remain in this browser, separate from manuscript drafts, corpus text,
editorial publications and shared review. Export bookmarks unchanged saves a JSON
backup, including an unreadable saved file for recovery. Bookmark-file import is
not supplied. From0.36, Include note attaches an individual annotation: opening the
bookmark highlights it in Research, and the saved citation includes its identifier.

Removal affects only the selected bookmark. Failed saves/removals leave the earlier
stored list unchanged. An invalid stored list disables changes and can still be
exported. The limit is 500 bookmarks per manuscript. Clearing browser data removes
local bookmarks; keep an export for long-term reference.

Isolated browser checks cover reload/navigation, passage and layer restoration,
literal labels, failed removal and unchanged recovery of malformed saved data.
