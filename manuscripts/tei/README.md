# Viṃśikā manuscript TEI export profile

Validation uses the pinned **TEI P5 4.12.0** Relax NG schema and additional checks
for the exact subset generated by this Reader. The original schema header and
dual CC BY / BSD-2 licensing declaration are retained. Its source URL and SHA-256
are in `schema-provenance.json`. The schema is a development resource; the Reader
does not download it when opening a manuscript.

The official references are the [TEI schema](https://www.tei-c.org/Vault/P5/4.12.0/xml/tei/custom/schema/relaxng/tei_all.rng)
and the definitions of [damage](https://www.tei-c.org/release/doc/tei-p5-doc/en/html/ref-damage.html)
and [addition](https://www.tei-c.org/release/doc/tei-p5-doc/en/html/ref-add.html).

Run from the site folder:

```
node scripts/export_manuscript_tei_fixtures.cjs
python scripts/validate_manuscript_tei.py
```

The validator requires Python with lxml. It makes no network requests and checks
the pinned schema hash before use. Generated fixtures live under `inspection`,
outside the site, and are explicitly synthetic QA cases, never source evidence.

The export profile checks:

- Valid TEI P5 structure and attributes, unique IDs, resolved physical targets.
- Original surface dimensions, image URLs and region coordinates.
- Physical reading order and separate diplomatic/transliteration/normalized/
  translation divisions; untranscribed layers do not acquire invented text.
- Exact Unicode reading text, extent, notes, passage targets and scholarly notes.
- Exact marked characters and offsets, including supplementary-plane characters.
- Preservation of mark explanations through linked notes.
- Review decisions, authenticated author references and reviewer/date attribution.

Mark explanations are notes linked to the exported mark's generated XML ID.
They are not placed in a `reason` attribute on `damage`, `add` or `del`, where
that attribute is invalid. This also preserves free-text explanations without
converting them into unsupported controlled vocabulary. Internal JSON marks,
character offsets and private drafts remain unchanged.

An unanchored manuscript exports a prose statement instead of an invalid empty
link group. XML-invalid control characters or unpaired surrogates cause a clear
export error; the original saved draft is retained without alteration.

Four positive cases cover the current pilot, all five mark types, completely
untranscribed lines and published review history. Negative cases prove detection
of invalid attributes, broken targets, altered text, shifted geometry, lost mark
explanations and false reviewer attribution.

This validates the Reader's generated subset, not every possible TEI document or
all of TEI's general-purpose Schematron rules. TEI is an interchange format;
complete private histories and review proposals remain in JSON. Passing schema
validation is not palaeographic or scholarly approval of a transcription.
