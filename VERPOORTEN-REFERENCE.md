The Reader indexes 201 Sanskrit headwords represented by its Sanskrit witnesses or lexical forms, with 209 page locations. The index retains spelling distinctions, uses case and punctuation normalization for exact links, and supports diacritic-insensitive prefix search plus Devanagari input in Analysis. It uses the headword at the start of a dictionary entry and omits abbreviated suffix expansions. Page links show the printed page and open the corresponding PDF page, which is five higher in this edition.

In Analysis → Lexicon, search for a headword, expand the publisher PDF in the Reader, or open it in a new tab. In Reading or Comparison, click a Sanskrit token for the primary reference and the Reader’s own glosses. The inflected *cittamātraṃ* opens *cittamātra* on printed page 237 (PDF 242). *Vijñapti* opens on printed page 697 (PDF 702). For forms outside the index, the full PDF link is always available. The search link passes the query to PDF viewers that support search fragments.

The publisher’s French and English definitions, school-specific senses and citations are available in the official edition. The upload contains only the headword locators and Reader code. The edition bears © 2025 Institut d’histoire des religions de l’Université de Strasbourg.
